# Academic Positioning

## Project Title

**Smart Municipal Works Monitoring and Decision-Support System with AI-Assisted Issue Classification**

## Contribution Statement

The project contribution is the integration of citizen issue reporting, image-based AI assistance, human confirmation, complaint-to-work association, explainable weighted priority scoring, rule-based delay risk detection, live project monitoring, and an administrative dashboard backed by real application data. These components form a unified decision-support workflow while preserving human responsibility for classification, associations, interpretation, and municipal action.

## AI-Assisted Classification

The image-analysis feature provides an AI-assisted issue candidate, relative prompt score, and suggested severity. It does not make a final municipal decision. The citizen must confirm, edit, reject, or replace the suggestion before submitting a complaint, and manual classification remains available when the AI service is unavailable.

The final complaint classification is stored separately from the AI output. Administrative actions, complaint-to-work links, priority interpretation, and project decisions remain human-controlled.

## Explainable Weighted Priority Scoring

Project priority is calculated from five configured, normalized factors and their visible weighted contributions. It is transparent decision-support logic, not a learned model, machine-learning prediction, official policy formula, or replacement for administrative review.

## Rule-Based Delay Risk Detection

Delay risk compares expected progress, actual progress, progress gap, completion, and deadline state against configured thresholds. It is an explainable advisory classification and not a machine-learning forecast of future performance.
